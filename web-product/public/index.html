BEFORE YOU DOWNLOAD

A local tool.
A few real requirements.

The package contains source, a prebuilt browser and a VS Code extension. It is not a standalone Windows .exe, and it does not include model weights or runtimes.

Read the setup guide ↗
  1. 1

    Prepare your computer

    Python 3.10+ and Node.js 24 LTS for initial setup. VS Code 1.90+ for Agent edits and commands. Git and ripgrep enable repository tools.

  2. 2

    Extract, install, launch

    Extract the ZIP and run python install.py. Setup installs dependencies and prepares Ollama when needed. Later, run python start.py.

  3. 3

    Choose local weights

    Initial software/model downloads need internet. Plan around 16 GB system RAM for the lighter 7B option; larger models need substantially more memory and disk.

THE PRACTICAL DETAILS

Know what you’re getting.

Will the model work as well as a hosted coding agent?

Results depend on your selected local model, hardware and task. One Qwen 2.5 Coder 7B run passed five of six small coding tasks; multi-file execution remained blocked. Other catalog models are research candidates, not locally validated equivalents. Review proposed work and use relevant checks.

Does my project go to a hosted AI account?

CodeMe connects to a loopback model server on your computer. Use a trusted runtime serving local weights. Installation and model downloads use the internet; the runtime and other installed software have their own behavior. Read the local data guide.

What does the package license allow?

Authorized purchasers can install and use the application for their own personal or internal business coding work, with private modifications and backup copies. Redistribution and resale require permission. Existing extension MIT and dependency/model licenses remain separate. Read the full license.
