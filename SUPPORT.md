# Get help with CodeMe

Start with [Getting started](docs/getting-started.md), [Configuration](docs/configuration.md), and [Troubleshooting](docs/troubleshooting.md). The [documentation index](docs/index.md) groups the remaining guides by task.

## Reproducible problems

Open a [bug report](https://github.com/DattaDhebe/codeme/issues/new/choose) for a reproducible application problem. Include:

- CodeMe version or commit and the client you used.
- Operating system, Python/Node versions when relevant, local runtime version, and exact model ID.
- Steps to reproduce, expected behavior, and the actual message or outcome.
- A small synthetic project or redacted log excerpt if needed.

Do not include `.env`, API keys, payment credentials, `codeme.db`, private conversations, customer information, or an entire private repository. Model setup progress, tool support, and coding quality are different signals; describe which one failed. For feature requests, explain the task you want to complete and the current limitation.

## Security and private matters

Use the process in [SECURITY.md](SECURITY.md) for suspected vulnerabilities. For a private installation or distribution question, contact **support@dhebe.com** and include only the details needed to understand it. No response-time or availability guarantee is provided.

The planned ₹499 Cashfree website checkout and protected CodeMe download are **not live yet**. A local ZIP does not establish a completed purchase or release. If the product is later activated, follow the published purchase and support instructions; never post payment screenshots, full receipts, or customer identifiers in a public GitHub issue.

## What support cannot infer

A passing unit suite does not prove a model performs well on your project. Only one catalog model has a recorded local evaluation in the current review. Other models and hardware need their own evaluation. Read [Model evaluations](docs/model-evaluations.md) and [Installation testing](docs/installation-testing.md) before comparing fixture tests with real inference or clean-machine results.
